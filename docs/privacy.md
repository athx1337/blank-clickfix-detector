# BLANK privacy policy

Applies to BLANK 0.2.0, updated 2026-11-01.

BLANK analyzes visible webpage instruction text on your device to warn about deceptive
copy-and-run requests. It does not transmit webpage text, URLs, findings, or settings to
the developer or any third party. There is no telemetry, analytics, account system,
advertising, cloud inference, or background model download.

Manual scans read the main document after you invoke the extension. Automatic scans
require both explicit site opt-in and browser website permission. Extraction excludes
form values, editable regions, hidden content, scripts and styles. Other visible text
may contain personal information; any extracted text stays in the browser.

Persistent extension storage contains the website patterns you enable for automatic scans.
The latest result for each scanned tab, including short evidence passages, remains in
trusted browser session storage until navigation, tab close, or browser restart. Automatic
scan caching uses temporary memory for up to 30 seconds. There is no saved scan history.
The extension removes pairing tokens left by its older local-server version.

Disable automatic scanning for a site in the popup or disable it everywhere in Settings.
You can separately revoke website access in your browser's extension settings. Removing
BLANK removes its extension storage. It does not access your clipboard, passwords, files,
other extensions' data, or OS commands.

Browser vendors may process information independently when distributing extensions;
their own privacy policies apply to their services. BLANK has no developer-operated
runtime service. Changes to this policy must accompany any future data-handling change.

Before a public store release, the publisher must supply a genuine support/privacy contact
and host this policy at a stable public URL. No publisher identity or contact is fabricated here.
